01 / Intake and automationRole: program manager and builderTools: Asana, Asana Node.js SDK, Claude Code

Intake and handoffs, automated

Problem. Creative requests arrived by too many routes, and final assets (design links, copy docs, images) got lost as work moved between related tasks. Native syncing across task levels wasn't available in our setup.

What I did. I built and run marketing intake and routing in Asana. Before writing any automation code, I had Claude Code interview me and test whether the platform could support the idea. Then I built Family Sync: a rule that carries final assets between related tasks, is safe to re-run, copies cleanly to other projects, and is documented. I paired it with team training so it stuck. Result. Quarterly deliverables rose roughly threefold, and median request-to-delivery time dropped by about a quarter (internal measures).
