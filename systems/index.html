01 / Intake and AutomationRole: Program Manager and BuilderTools: Asana, Asana Node.js SDK, Claude Code

Intake and Handoffs, Automated

Problem. Creative requests arrived by too many routes, and final assets (design links, copy docs, images) got lost as work moved between related tasks. Native syncing across task levels wasn't available in our setup.

What I did. I co-designed and co-built our Asana implementation for marketing requests from scratch, with the team that runs intake, and I handled the technical build. Before writing any automation code, I had Claude Code interview me and test whether the platform could support the idea. Then I built Asana Tasks Family Sync: a rule that carries final assets between related tasks, is safe to re-run, copies cleanly to other projects, and is documented. I paired it with team training so it stuck. Result. Final assets, including design links, copy docs, and video, now follow the work automatically, so nobody has to hunt for the latest file.

03 / AI ToolingRole: Program Manager and BuilderTools: Asana, Asana Node.js SDK, Claude Code

Campaign Builder

Problem. Setting up a campaign meant rebuilding the same task structure by hand, and the brief and the tasks drifted apart.

What I did. I built and piloted a brief-to-project automation in Asana that turns a campaign brief into tasks and dependencies. A pilot run generated a full parent task and its subtasks straight from a brief. I paused the broader rollout until the underlying request data was ready. Result. A working pattern for turning one brief into a complete, routed project, ready to extend.

04 / AI ToolingRole: Program Manager and BuilderTools: Asana, Claude

AI Tooling at Work

Problem. A marketing work system lives in a lot of people's heads, and incomplete requests turn into rework.

What I'm building. Four AI initiatives, all on tools we already own.
Brief to Campaign: one campaign brief becomes a complete, routed Asana project (built and piloted).
Claude Asana Project: a living operating manual for marketing's work system, in a Claude knowledge base that updates when the rules change (in progress).
AI Intake Triage: catching incomplete requests at the door, before they become rework (in progress).
Automated Status Updates: stakeholders get status without asking, starting with blocked-work alerts (early stage).
