Body 1 (ARTROCK Studio Forge): Left Hemisphere runs a KV-pinned 27B reasoning model on an RTX 3090 Ti (24 GB) for analytical synthesis; Right Hemisphere runs a 9B vision model on an RTX 5070 eGPU (12 GB) for 5-candidate photography grading.

Body 3 (Midnight Watchdog): Linux server + RX 550 running 1.7B + Nomic embeddings, Home Assistant VM, and cloud telemetry pollers.

APPA: Autonomous Post-Production Pipeline

As credited Producer on Ben Windle Shoots His Shot (@BenWindleShootsHisShot), I built APPA to eliminate a 15-to-20-hour weekly manual logging and rough-cut bottleneck. APPA ingests raw multi-camera field footage, runs WhisperX speaker-verified transcription and computer-vision scene grading, and compiles frame-accurate 24fps .fcpxml, .otio, and burnt-in 2-lane review proxies for Premiere Pro and DaVinci Resolve.
